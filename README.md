# AiM One Health website mockup

A redesign concept for aimonehealth.com: eight linked pages in a liquid-glass style with Daylight/Night themes, an icon sidebar, 3D card transitions between pages and a phone layout. Content is from the live site, reorganized for readability.

## Run

```
Double-click "Open mockup.cmd" (needs Python), or serve the folder with any static web server.
```

Design mockup only; forms don't send anything.
